# SHAPify

This package is scoped to personal shape fitting:

- `fit_shape.py`: body-measurement based shape fitting.
- `fit_shape_wild.py`: in-the-wild shape fitting demo.
- `config.py`: shared SHAPify defaults and SMPL factory helpers.
- `geometry.py`: projection and rotation utilities used by SHAPify.
- `visualize.py`: shape comparison visualizer.

PointDiT training/inference code lives in `phd/`; body fitting and EMDB evaluation live in `fitting/`.
